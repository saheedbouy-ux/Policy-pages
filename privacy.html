Privacy Policy

Last updated: September 9, 2026

AnythingViral is a personal automation tool used to post content to the operator's own TikTok account via the TikTok Content Posting API. This application does not collect, store, or share personal data belonging to any third party.

Any credentials or tokens used by this application (such as TikTok API access tokens) are stored locally and privately by the operator and are never shared with or sold to any third party.

For questions, contact the operator via the associated TikTok profile.
